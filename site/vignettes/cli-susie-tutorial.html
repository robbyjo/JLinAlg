Fine-map one locus from files.

Supply summary statistics, LD, and sample size; receive PIPs, credible effects, convergence provenance, and coloc-ready evidence.

Version availabilityThe susie CLI command was added after v0.3.4. Use current jlinalg-0.3.5-SNAPSHOT.jar or a later release; it is not present in the published v0.3.4 JAR.
Shell syntaxWebsite command blocks use the POSIX-shell \ line continuation. In PowerShell replace it with a backtick or put the command on one line.

1. Define and harmonize the locus

Use one genome build, unambiguous unique variant IDs, allele-aligned summary effects, and ancestry-matched LD. Summary CSV/TSV needs either z:

variant_id,z
rs1001,8.42
rs1002,2.13
rs1003,-6.90

or beta and positive SE:

SNP,beta,se,effect_allele,other_allele
rs1001,0.168,0.020,A,G
rs1002,0.041,0.019,C,T
rs1003,-0.138,0.020,T,C

Standard names are detected. Use --variant-column, --z-column, or paired --beta-column/--se-column for custom names. Allele columns are provenance: this command does not flip alleles or perform liftover.

2. Supply safe LD

An unlabeled square matrix must be in exact summary-row order. A labeled matrix is safer and is automatically reordered:

variant_id,rs1003,rs1001,rs1002
rs1003,1.0,0.02,0.08
rs1001,0.02,1.0,0.31
rs1002,0.08,0.31,1.0

Row and column IDs must be unique and equal the summary variant set. LD must be finite, symmetric, positive semidefinite, and have a correlation diagonal. Singular LD is allowed; indefinite or inconsistent LD is rejected.

3. Run SuSiE

Summary-statistic fine mapping
java -jar jlinalg-<version>.jar susie \
  --summary locus-summary.csv --ld locus-ld.csv --sample-size 125000 \
  --effects 10 --coverage 0.95 --min-purity 0.5 \
  --max-iterations 200 --tolerance 1e-6 \
  --out locus-susie.csv

Defaults are 10 effects, 200 iterations, tolerance 1e-6, prior variance 0.2, 95% coverage, purity 0.5, and estimated residual variance. Use --fixed-residual-variance only when planned. --backend cpu forces the portable path.

4. Read the three outputs

  1. locus-susie.csv: variant ID, PIP, and posterior mean.
  2. locus-susie.csv.effects.tsv: every locus variant for each retained credible effect, including alpha, effect mean, log Bayes factor, membership, coverage, and purity. The one-based effect index is preserved. This is direct coloc input.
  3. locus-susie.csv.log: inputs, sample size, counts, iterations, convergence, objective, residual variance, backend, and paths.

Choose sidecars with --effects-output FILE --log FILE. Each output's own suffix controls commas versus tabs. Existing files require --overwrite.

5. Check before interpreting

  • Require converged=true.
  • Read PIP together with credible-set membership, coverage, and purity.
  • Check sensitivity to effect count, prior variance, locus boundary, and LD source.
  • Remember that summary-mode posterior means are on the standardized summary-statistic scale, not automatically original GWAS units.

If no effect passes the purity rule, the effects sidecar has only its header. Do not lower purity after seeing a desired answer without reporting that decision.

Common failuresID mismatch calls for a labeled LD matrix or an explicit input intersection. Indefinite LD calls for checking order, alleles, missingness, and LD calculation—not replacing LD with identity. An ancestry mismatch calls for a better reference.

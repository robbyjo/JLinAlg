Smooth the mean—or the whole distribution.

Compile bases once, select single or marginal penalties, add pedigree and correlated covariance, and reuse the result for high-throughput association.

Fit a REML GAM

Gaussian P-spline
PSplineTerm age = PSplineTerm.of(
    "s(age)", ageYears, 12);
GamResult fit = Gam.fitGaussian(
    phenotype, fixedDesign, List.of(age));

double beta = fit.parametricCoefficients()[1];
double se = fit.parametricStandardErrors()[1];
double t = fit.parametricTStatistics()[1];
double p = fit.parametricPValues()[1];

Gaussian smoothing is an exact mixed-model REML fit. Profile ML and residual, Satterthwaite, or Kenward–Roger inference are selected through RemlOptions. Generalized GAMs accept every built-in GLM family, offsets, and prior weights.

Use anisotropic tensor penalties

te() with GCV
CompiledQuadraticGamFormula model =
    AdvancedGamFormula.compile(
        "y ~ sex + te(age,bmi,kx=8,kz=7)", table);

GaussianSmoothSelectionResult result =
    model.fitGaussian(
        SmoothingSelectionOptions.gcv(),
        BackendPolicy.PREFERRED);

QuadraticSmoothTerm retains multiple penalties. te() estimates a penalty for each margin; ti() removes marginal trends for interaction-only terms. Fixed, GCV, UBRE, and AIC selection share the same compiled representation.

Choose a smooth basis

Constructors cover P-splines, cyclic periodic terms, low-rank two-dimensional thin plates, tensor products, varying coefficients, random-effect smooths, and graph-Laplacian Markov random fields. Identifiability is imposed once when null spaces are compiled.

Combine smooths and relatedness

Pedigree Laplace GAMM
VarianceComponent animal =
    GammCovariances.pedigree(
        "animal", observationIds, pedigree);

GeneralizedGammLaplaceResult fit =
    GeneralizedGammLaplace.fit(
        y, fixedDesign, List.of(age),
        GlmFamilies.binomial(), List.of(animal),
        weights, offset,
        GlmmLaplaceOptions.defaults(),
        BackendPolicy.PREFERRED);

Exact Gaussian REML accepts grouped, pedigree, cryptic-relatedness/GRM, and residual covariance components. Non-Gaussian fits offer fast PQL and an accuracy-oriented dense first-order Laplace marginal likelihood. ArmaCorrelation supplies stationary AR/MA/ARMA residual matrices.

Model location, scale, shape, or category

Parameter-specific formulas
DistributionalResult fit =
    DistributionalFormula.fit(
        List.of("y ~ s(age,k=10)",
                "y ~ sex + s(age,k=7)"),
        List.of(List.of(new double[]{0.8}),
                List.of(new double[]{2.0})),
        table,
        DistributionalFamilies
            .gaussianLocationScale(),
        FormulaOptions.defaults(),
        DistributionalOptions.defaults(),
        BackendPolicy.PREFERRED);

Gaussian, Gamma, Beta, NB2, zero-inflated, hurdle, multinomial, and ordinal families use one linked additive predictor per parameter. Prepared warm refits, prediction, quantile residuals, centiles, likelihood-ratio comparison, and AIC are available.

Vector-response probabilities
double[][] probability =
    DistributionalPrediction.categoryProbabilities(
        fit, parameterPredictors,
        DistributionalFamilies.multinomial(3));

The returned matrix is observation by category and each row sums to one. Deterministic Java tests compare the Gaussian location/scale path with gamlss and multinomial logits, likelihood, and probabilities with VGAM.

Scan markers against one smooth null

Prepared GAM association
try (PreparedGamAssociation scan =
        new PreparedGamAssociation(
            nullFit,
            AssociationEngineOptions
                .acceleratedSerial())) {
    AssociationBatchResult hits =
        scan.scan(genotypes, variantNames);
}

The null penalty factorization is retained. Each marker block uses a batched cross-product and returns beta, SE, t, regular p, log10-p, and −log10-p. DiscretePSplineBasis aggregates repeated covariate rows for BAM-like cross-products.

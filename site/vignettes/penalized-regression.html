Shrink, select, and validate.

Fit ridge, LASSO, and elastic-net models with standardized coordinate descent, warm regularization paths, and deterministic cross-validation.

v0.3.0 audit updateWeighted paths and CV preserve their intended risk and penalty scaling, reject unconverged paths, and avoid cancellation in near-perfect residual sums. Active-set refits alone are not selection-aware inference: use the documented held-out or fixed-penalty Gaussian selective methods with their assumptions. Updated guide and evidence →

CLI-only regularized regression

Ridge, LASSO, and elastic-net commands
java -jar jlinalg-0.3.5.jar penalized-regression --input continuous.tsv --response y --predictors x1,x2,x3 --model ridge --lambda 0.1 --out ridge.tsv
java -jar jlinalg-0.3.5.jar penalized-regression --input continuous.tsv --response y --predictors x1,x2,x3 --model lasso --lambda-grid 1,0.3,0.1,0.03 --cv-folds 10 --out lasso.tsv
java -jar jlinalg-0.3.5.jar penalized-regression --input continuous.tsv --response y --predictors x1,x2,x3 --model elastic-net --alpha 0.5 --lambda-grid 1,0.3,0.1,0.03 --cv-folds 10 --out elastic-net.tsv

The numeric CSV/TSV input has variables in columns. Intercept and standardization are enabled by default; use --no-intercept or --no-standardize deliberately. The specialized CLI fits paths and cross-validation; the selection-aware inference APIs later on this page are Java-only.

Fit three penalties

Supply predictor columns without a manual intercept; the penalized fitter handles its unpenalized intercept separately.

Ridge, LASSO, elastic net
PenalizedRegressionResult ridge =
    PenalizedRegression.ridge(y, predictors, .1);
PenalizedRegressionResult lasso =
    PenalizedRegression.lasso(y, predictors, .1);

ElasticNetOptions options = ElasticNetOptions.builder()
    .alpha(.5)       // 0 ridge; 1 LASSO
    .standardize(true)
    .build();
PenalizedRegressionResult elastic =
    PenalizedRegression.fit(y, predictors, .1, options);

Coefficients return on the original predictor scale. Positive observation weights and per-coefficient penalty factors are available in the options builder.

Build a warm lambda path

Automatic path
PenalizedRegressionPath path =
    PenalizedRegression.automaticPath(
        y, predictors, 100, 1e-4, options);

for (int i = 0; i < path.size(); i++) {
    System.out.println(path.fit(i)
        .activeCoefficientCount());
}

The path is descending in lambda and warm-started. The maximum lambda begins at an intercept-only LASSO solution.

Select lambda without leakage

Deterministic K-fold CV
PenalizedCrossValidationResult cv =
    PenalizedRegressionCrossValidation.automatic(
        y, predictors, 100, 1e-4,
        10, 20260901L, options);

double lambdaMin = cv.lambdaMinimum();
double lambdaOneSe = cv.lambdaOneStandardError();
PenalizedRegressionResult conservative =
    cv.oneStandardErrorFit();

Preprocessing is learned independently inside every training fold. The one-SE choice is usually the simpler model within one standard error of minimum CV error.

Handle inference honestly

Ridge has effective-DF model-based inference:

Ridge association statistics
RidgeRegressionResult inference =
    PenalizedRegressionInference.ridge(
        y, predictors, lambdaMin, options,
        BackendPolicy.PREFERRED);
AssociationStatistics stats =
    inference.associationStatistics();
Selection warningAn OLS refit of a LASSO/elastic-net active set is conditional on selection. Its ordinary p-values are not selection-adjusted and should not be marketed as such.

Selection-aware alternatives

SelectionAwarePenalizedInference selects on one sample and fits weighted OLS inference on independent held-out rows, preserving penalty factors and split weights. High-dimensional selection is permitted when the held-out selected design is identifiable.

PolyhedralSelectiveInference conditions on the active set and signs at a fixed LASSO/elastic-net penalty and returns truncated-Gaussian p-values and inverted intervals for selected-model projection coefficients. It requires independently known Gaussian noise SD, unstandardized predictors, and tuning choices fixed independently of the response. It does not make ordinary post-selection OLS p-values valid.

CLI-only quick starts

These commands need only an executable JAR. The published v0.3.5 asset supports the OLS, logit, and Poisson examples; probit requires a current source build produced by gradlew executableJar. Phenotype rows missing the response or any formula variable are omitted together, and a .csv output is comma-separated.

Phenotype-only OLS
java -jar jlinalg-0.3.5.jar --pheno phenotype.csv --id SampleName --formula "BMI ~ Sex + Age" --out bmi-ols.csv
Binary and count omics GLMs
java -jar jlinalg-0.3.5.jar --pheno phenotype.csv --omics expression.csv --id SampleName --formula "case_status ~ Sex + Age + <omics>" --family binomial --case-value case --control-value control --out case-expression.csv
java -jar build/cli/jlinalg-0.3.5.jar --pheno phenotype.csv --id SampleName --formula "case_status ~ Sex + Age" --family probit --case-value case --control-value control --out case-probit.csv
java -jar jlinalg-0.3.5.jar --pheno phenotype.csv --omics expression.csv --id SampleName --formula "count ~ Sex + Age + <omics>" --family poisson --out count-expression.csv

Use --family gamma for positive continuous outcomes. Add --dry-run to inspect alignment and routing without fitting; see the complete CLI guide for transforms, annotations, and mixed models.

Fit an ordinary linear model

JLinAlg does not add an intercept silently. Put a column of ones in the design when the model needs one.

OLS with intercept and slope
double[] y = {1, 2, 5, 7, 9};
double[][] x = {
    {1, 0}, {1, 1}, {1, 2}, {1, 3}, {1, 4}
};

OlsResult fit = Ols.fit(y, x);
System.out.println(Arrays.toString(fit.coefficients()));
System.out.println(Arrays.toString(fit.standardErrors()));
System.out.println(Arrays.toString(fit.tStatistics()));
System.out.println(Arrays.toString(fit.pValues()));

The slope is fit.coefficients()[1]. Its t test uses N-rank(X) residual DF. Check fit.rank(), residual plots, and influence outside the library before interpreting the model.

Add weights, offsets, and missing policy

Weighted OLS
double[] weights = {1, 1, 2, 2, 1};
double[] offset = {0, 0, .2, .2, .2};
OlsOptions options = new OlsOptions(
    RankDeficiencyStrategy.ERROR, .95,
    MissingDataPolicy.OMIT);

OlsResult weighted = Ols.fit(
    y, x, weights, offset, options,
    BackendPolicy.PREFERRED);
int[] sourceRows = weighted.retainedRows();
Offset semanticsOLS subtracts the additive response-scale offset before solving. Positive weights control precision; they are not frequency expansion.

Fit binary and count outcomes

The family supplies the link, variance, deviance, and likelihood contract. Fixed-dispersion GLM coefficient tests use Wald z inference; estimated-dispersion families use residual Student t inference.

Logistic, probit, and Poisson models
GlmResult logistic = Glm.fit(
    disease, design, GlmFamilies.binomial());

GlmResult probit = Glm.fit(
    disease, design, GlmFamilies.probit());

double[] logExposure = Arrays.stream(exposure)
    .map(Math::log).toArray();
GlmResult poisson = Glm.fit(
    counts, design, GlmFamilies.poisson(),
    null, logExposure, GlmOptions.defaults(),
    BackendPolicy.PREFERRED);

if (!poisson.converged())
    throw new IllegalStateException("IRLS did not converge");

GlmFamilies.binomial() uses a logit link; probit() and its binomialProbit() alias use the standard-normal CDF with stable smaller-tail calculations. Also available: Gaussian/identity, Gamma/log, inverse-Gaussian/log, fixed-size negative-binomial/log, quasi-binomial, and quasi-Poisson. For grouped binomial data use response proportions with trial counts as prior weights.

Test a scientific contrast

Joint coefficient hypothesis
double[][] contrast = {
    {0, 1, 0},
    {0, 0, 1}
};
ContrastTestResult test = fit.testContrast(contrast);

OLS returns a finite-DF F test. Fixed-dispersion GLMs return an asymptotic chi-square Wald test; estimated-dispersion GLMs return a residual F test. A rank-deficient design fails unless a minimum-norm SVD solution is explicitly requested.

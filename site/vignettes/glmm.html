CLI-only glmer-like workflows

Grouped binary and count GLMMs
java -jar jlinalg-0.3.5.jar --pheno phenotype.csv --id SampleName --formula "case_status ~ Sex + Age + (1|clinic)" --family binomial --case-value case --control-value control --out case-clinic.csv
java -jar jlinalg-0.3.5.jar --pheno phenotype.csv --omics expression.csv --id SampleName --formula "count ~ Sex + Age + <omics> + (1|clinic)" --family poisson --out count-expression-clinic.csv
Pedigree binary omics GLMM
java -jar jlinalg-0.3.5.jar --pheno phenotype.csv --omics expression.csv --id SampleName --individual-id sabreid --formula "case_status ~ Sex + Age + <omics> + (1|sabreid)" --family binomial --case-value case --control-value control --pedigree pedigree.csv --pedigree-id sabreid --sire-id fid --dam-id mid --out case-expression-pedigree.csv

These CLI models use first-order Laplace fitting and refit every numeric feature, matching the glmer-like pathway. PQL, adaptive quadrature, and zero-inflated models on the rest of this page are currently Java APIs.

Construct random covariance

PQL uses the same observation-scale random covariance bases as dense REML. Build a group block without hand-writing a matrix:

Random intercept basis
VarianceComponent group =
    VarianceComponent.randomIntercept(
        "clinic", clinicIds);

Fit a count mixed model

Poisson PQL
GlmmPqlResult fit = GlmmPql.fit(
    counts, fixedDesign,
    GlmFamilies.poisson(),
    List.of(group));

if (!fit.converged())
    throw new IllegalStateException(
        fit.convergenceMessage());

AssociationStatistics inference =
    fit.associationStatistics();

The full overload accepts positive prior weights, log exposure as an offset, PQL iteration controls, and a backend policy.

Fit a binary pedigree GLMM

Pedigree binomial PQL
PedigreeGlmmPqlResult pedigreeFit =
    PedigreeGlmmPql.fit(
        affected, fixedDesign,
        GlmFamilies.binomial(),
        observationAnimalIds, pedigree);

Supported families include binomial, Poisson, fixed-size negative-binomial, and appropriate quasi families. Gaussian responses belong in exact REML/LMM APIs.

Fit a frequentist zero-inflated pedigree model

NB2-ZINB sparse Laplace
PedigreeRandomEffectTerm additive =
    PedigreeRandomEffectTerm.of(
        "individual", observationIndividualIds,
        pedigree);

CorrelatedZeroInflatedRandomEffect joint =
    CorrelatedZeroInflatedRandomEffect
        .pedigree("additive", additive);

try (SparseZeroInflatedMixedModel.Prepared prepared =
        SparseZeroInflatedMixedModel
            .prepareNegativeBinomial(
                counts.length,
                List.of(), List.of(),
                List.of(), List.of(),
                List.of(joint),
                ZeroInflatedMixedOptions.defaults(),
                BackendPolicy.PREFERRED)) {
    ZeroInflatedMixedResult fit =
        prepared.fitWithInference(
            counts, countDesign, countColumns,
            zeroDesign, zeroColumns,
            sizeDesign, sizeColumns,
            logExposure);
}

Random effects may enter either process. A correlated pedigree effect estimates two variances and a guarded correlation with precision inverse(G) kron inverse(A). Zero observations contribute the full observed count/zero cross-Hessian. BOBYQA itself remains derivative-free; optional covariance comes from a separate post-fit numerical Hessian of the marginal Laplace objective.

Prepared fits reuse one symbolic sparse analysis and one numeric factor per worker, and also support profile grids and deterministic conditional parametric bootstrap. Checked-in glmmTMB and independent TMB sparse-GMRF fixtures gate estimates, marginal likelihood, and standard errors. The result distinguishes the conditional count mean, structural-zero probability, unconditional mean, and total zero mass.

Interpret the working fit

Each outer iteration creates a GLM working response and known diagonal residual covariance, estimates random covariance scales by REML, then updates the random linear predictor.

PQL is not a marginal GLMM likelihoodIt can be biased for rare binary events, small clusters, and large random-effect variance. Satterthwaite or Kenward–Roger options apply to the final working linearization—not the exact non-Gaussian model.

Report the estimator as PQL, check both inner and outer convergence, and avoid likelihood comparisons with Laplace/AGQ fits.

Adaptive random-intercept quadrature

GlmmQuadrature uses per-group mode/curvature-adaptive Gauss–Hermite nodes and node refinement for binomial or Poisson responses, including trials and offsets. Fits compare the zero-variance boundary and expose joint covariance and numerical integration diagnostics.

R integrate and lme4 high-node AGQ fixtures check full likelihood, coefficients, SD, and covariance. Java is faster on the measured count examples and slower on rare/binary examples. This API handles independent scalar Gaussian random intercepts, not pedigree, crossed, or multidimensional random effects. Refinement is an error diagnostic, not a certified exact integral.

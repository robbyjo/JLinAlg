Nonlinear means, explicit random effects.

Fit an analytic mean function with deterministic Gaussian least squares, then add sparse ordinary or pedigree random effects.

Supply a mean and gradient

NonlinearMeanFunction exponential = (theta, row) -> {
    double x = row * 0.25;
    double mean = theta[0] * Math.exp(theta[1] * x);
    return new NonlinearMeanFunction.Evaluation(mean,
        new double[] {Math.exp(theta[1] * x), x * mean});
};
NonlinearFitResult fit = NonlinearFixedModel.fit(
    response, new double[] {1.0, 0.1}, exponential,
    NonlinearModelOptions.defaults(), BackendPolicy.CPU);

Check converged() before interpreting beta(), local standard errors, or the residual objective. Nonlinear parameterization and starting values matter; analytic gradients must match the supplied mean.

Add a sparse group effect

RandomEffectTerm group = RandomEffectTerm.randomIntercept("site", siteIds);
NonlinearMixedFitResult mixed = NonlinearMixedModel.fit(
    response, new double[] {1.0, 0.1}, exponential,
    List.of(group), RemlOptions.defaults(),
    NonlinearModelOptions.defaults(), BackendPolicy.CPU);

Include pedigree structure

PedigreeRandomEffectTerm additive = PedigreeRandomEffectTerm.of(
    "additive", observationIds, pedigree);
NonlinearMixedFitResult animal = NonlinearMixedModel.fitPedigree(
    response, new double[] {1.0, 0.1}, exponential,
    List.of(additive), List.of(), RemlOptions.defaults(),
    NonlinearModelOptions.defaults(), BackendPolicy.CPU);

Unphenotyped ancestors remain in the coefficient system. The model is y = f(theta,x) + Zb + e: random effects are additive on the response scale. Inspect linearizedModel() for variance components, conditional modes, and sparse diagnostics.

Statistical boundary and audit

The mixed path uses local Gaussian linearization and REML updates. It is not a general nonlinear random-parameter model, exact nlme likelihood, or non-Gaussian adaptive quadrature. Version 0.3.0 checks the projected correction and final Jacobian instead of accepting a tiny damped step. Large shared response offsets can quantize a near-optimal fit and prevent a score certificate; that case now reports nonconvergence rather than accepting a response-scale floor. Independent R fixtures and reviewer counterexamples cover these limits.

Basic tests, explicit inference.

A shared immutable test result for correlations, contingency tables, blocked ranks, mean/variance tests, and proportions. ANOVA power uses its own power-analysis result.

Use the common result

StatisticalTestResult fit = StatisticalTests.correlation(
    new double[] {1, 2, 3, 4, 5, 6},
    new double[] {2, 1, 4, 3, 6, 5});
System.out.println(fit.estimates());
System.out.println(fit.pValue());
System.out.println(fit.confidenceInterval());

The Pearson example returns correlation 0.8285714285714286 and two-sided p approximately 0.04156268. The 0.3.0 implementation preserves this inference when measurement units change, avoiding intermediate square overflow and underflow.

Know which rank test ran

Default Kendall inference is exact below 50 untied pairs and normal otherwise. Explicit exact requests use a normalized, symmetric-tail recurrence, with a 50-million-cell bound that fails explicitly rather than silently approximating. Spearman uses exact enumeration through nine pairs, AS 89 through 1,289, then Student t. Ties, including positive/negative zero, select the corresponding asymptotic calculation. Inspect pValueMethod().

Validation and speed

Base-R fixtures cover both cutoffs, ties, ANOVA, and scale-invariant mean/variance inference. An independent quadratic oracle checks the new O(n log n) Kendall counting path. On a local 5,000-pair tied workload, Java took about 2 ms versus base R's 130 ms; timings are workload-specific.

Boundaries

Sample APIs reject NaN/infinity; compact common complete cases before fitting. Welch ANOVA needs positive variance in each group. Classical ANOVA permits a constant group when pooled within-group variance is positive. Exact rectangular Fisher enumeration has an explicit table-count limit. A finite p-value is not a check of modeling assumptions.

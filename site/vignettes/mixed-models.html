Variance structure without a black box.

Start from known covariance bases or named random terms, choose dense or sparse equations deliberately, and retain the full inference contract.

Fit covariance-component REML

Random-intercept REML
List<VarianceComponent> components = List.of(
    VarianceComponent.randomIntercept(
        "subject", subjectIds),
    VarianceComponent.identity("residual", y.length));

RemlResult fit = Reml.fit(y, fixedDesign, components);
if (!fit.converged())
    throw new IllegalStateException(
        fit.convergenceMessage());

System.out.println(Arrays.toString(
    fit.varianceComponents()));

Each basis is known; REML estimates only its nonnegative scale. Use profile ML—not REML—to compare nested models with different fixed-effect designs.

Use named random terms

Crossed intercept and independent slope
List<RandomEffectTerm> random = List.of(
    RandomEffectTerm.randomIntercept(
        "subject", subjectIds),
    RandomEffectTerm.randomSlope(
        "subject:age", subjectIds, age),
    RandomEffectTerm.randomIntercept(
        "batch", batchIds));

LinearMixedModelResult lmm =
    LinearMixedModel.fit(y, fixedDesign, random);
double[] modes = lmm.randomEffects("subject")
    .estimates();

The slope and intercept above have independent variances. Use CorrelatedLinearMixedModel or (1 + age | subject) formula syntax when covariance must be estimated.

Switch to sparse precision equations

Sparse LMM
SparseLinearMixedModelResult sparse =
    SparseLinearMixedModel.fit(
        y, fixedDesign, random,
        RemlOptions.builder()
            .initialVariances(1, 1, 1, 1)
            .build(),
        BackendPolicy.PREFERRED);

Provide one initial variance per random term plus residual. Sparse equations avoid observation-scale covariance matrices; dense REML remains the reference path for full PEVs and finite-DF adjustments.

Choose denominator degrees of freedom

Kenward–Roger
RemlOptions smallSample = RemlOptions.builder()
    .degreesOfFreedomMethod(
        DegreesOfFreedomMethod.KENWARD_ROGER)
    .build();

The fast default is N-rank(X)-1. Satterthwaite and Kenward–Roger are coefficient-specific dense options and cost more.

Predict and refit

New levels and repeated responses
double[] population =
    MixedModelPrediction.marginal(lmm, newX);
double[] conditional =
    MixedModelPrediction.conditional(
        lmm, newX, newRandomTerms, true);

PreparedLinearMixedModel prepared =
    PreparedLinearMixedModel.of(fixedDesign, random);
LinearMixedModelResult first = prepared.fit(y);
LinearMixedModelResult next =
    prepared.refit(first, anotherResponse);

With allowNewLevels=true, unseen groups receive random mode zero. Prepared refits retain design structure and warm-start variance estimates.

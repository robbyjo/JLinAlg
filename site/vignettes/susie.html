Fine-map signals, not only variants.

Iterative Bayesian stepwise selection from individual data, z scores plus LD, or caller-supplied sufficient statistics, with PIPs and purity-filtered credible sets.

Validated and benchmarkedOn susieR's 574-by-1,001 N3finemapping vignette data, PIPs and coefficients match within 2e-10 and JLinAlg's portable CPU path is 4.83 times faster on the documented host.

Set the single-effect model

SuSiE controls
SusieOptions options = new SusieOptions(
    5,      // maximum effects L
    200,    // iterations
    1e-8,   // convergence tolerance
    .2,     // absolute prior variance on standardized X
    true,   // estimate residual variance
    .95,    // credible-set coverage
    .5);    // minimum purity

The maximum effect count is a modeling choice. Inspect whether extra single effects remain diffuse rather than interpreting every component as a discovery.

Fit individual-level data

Samples by variants
SusieResult fit = Susie.fit(
    phenotype, genotypeMatrix, variantNames,
    options, BackendPolicy.CPU);

if (!fit.converged())
    throw new IllegalStateException(
        "SuSiE did not converge");

double[] pip = fit.pip();
double[] beta = fit.posteriorMean();
List<CredibleSet> sets = fit.credibleSets();

Individual predictors are centered/scaled once. Posterior means return on the original scale with a fitted intercept.

Fit z scores and LD

Summary fine mapping
SusieResult summary = Susie.fitSummary(
    zScores, ldCorrelation, sampleSize,
    variantNames,
    new SusieOptions(
        5, 200, 1e-8, .2,
        false, .95, .5),
    BackendPolicy.CPU);

Summary mode uses susieR's finite-sample z transformation. LD must match variant order, ancestry, and allele orientation; as with susieR's default input checks, no eager cubic positive-semidefinite factorization is performed.

Use sufficient statistics

When the standardized summary assumptions do not match the data scale, call fitSufficientStatistics with X′X, X′y, y′y, sample size, names, options, and backend.

Read sets with PIPsCredible-set purity is the minimum absolute within-set LD. Report coverage, purity, member variants, PIPs, and the LD reference together.

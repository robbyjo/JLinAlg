Multivariable is not multivariate.

Use separate, schema-checked commands for multiple-exposure MVMR and covariance-aware joint inference on correlated outcomes.

Current source buildBuild the executable with gradlew.bat assemble. On this checkout it is build/cli/jlinalg-0.3.5.jar. Published release JARs predating these commands do not contain them.

Prepare one complete wide table

variant_id  beta_exposure_bmi  se_exposure_bmi  beta_exposure_ldl  se_exposure_ldl  beta_outcome_cad  se_outcome_cad  beta_outcome_stroke  se_outcome_stroke
rs101       0.08               0.02              0.03               0.01             0.025             0.010           0.018                0.012

Clump the exposure instruments once and harmonize every association to the same effect allele first. Every selected variant must have all selected exposure and outcome associations; the joint commands do not guess allele orientation or change the instrument set by outcome.

Run multivariable MR

Multiple exposures, one outcome
java -jar build/cli/jlinalg-0.3.5.jar mr-mvmr `
  --input harmonized-wide.tsv `
  --exposures bmi,ldl --outcome cad `
  --method ivw --backend cpu `
  --output mvmr-cad.tsv

Each coefficient is a direct effect conditional on the other listed exposures. --method egger adds a multivariable intercept. The reported marginal_f is not conditional strength; conditional F inference requires cross-exposure sampling covariance through the Java covariance-aware MVMR API.

Supply outcome-association correlation

1.00  0.42
0.42  1.00

The headerless matrix follows --outcomes exactly and must be finite, symmetric, positive definite, and have unit diagonal. It represents correlation among estimated SNP-outcome associations—not automatically phenotypic correlation. Record how it was estimated and the relevant sample overlap.

Run multivariate MR-IVW

Multiple correlated outcomes
java -jar build/cli/jlinalg-0.3.5.jar mr-multivariate `
  --input harmonized-wide.tsv `
  --exposures bmi,ldl --outcomes cad,stroke `
  --outcome-correlation outcome-correlation.tsv `
  --method ivw-fixed --backend cpu `
  --output multivariate-mr.tsv `
  --plot multivariate-mr-forest.svg

The generalized least-squares model estimates every exposure-outcome cell and propagates outcome correlation into the coefficient covariance. It reports cell tests, per-exposure and per-outcome joint Wald tests, an overall test, multivariate Cochran Q, and dispersion. Choose ivw-random for multiplicative-random standard errors. --plot writes a dependency-free SVG forest plot of every effect and confidence interval.

Run multivariate MR-PRESSO

Mahalanobis bootstrap diagnostic
java -jar build/cli/jlinalg-0.3.5.jar mr-multivariate `
  --input harmonized-wide.tsv `
  --exposures bmi,ldl --outcomes cad,stroke `
  --outcome-correlation outcome-correlation.tsv `
  --method presso --simulations 10000 --seed 20260916 `
  --output multivariate-presso-effects.tsv `
  --diagnostics multivariate-presso-instruments.tsv

The diagnostic combines leave-one-instrument-out residual vectors, Mahalanobis distance, a reproducible parametric bootstrap, and Bonferroni-adjusted instrument tests. Results contain raw and, when estimable, outlier-corrected fits. Report all exclusions; outlier removal does not prove instrument validity.

Use xWAS for screening, then fit jointly

  1. Clump each exposure once.
  2. Screen all pairs with mr-xwas and complete-family BH FDR.
  3. Prespecify the related-outcome family and construct a complete wide table.
  4. Estimate the outcome-association correlation matrix.
  5. Run mr-multivariate as the joint follow-up.

A loop of univariate MR fits cannot reproduce covariance-aware joint tests.

Do not relabel other published models

Method boundarymr-multivariate implements summary-data multivariate MR-IVW and a Mahalanobis/bootstrap multivariate MR-PRESSO diagnostic. It is not MR²'s sparse Bayesian Gaussian-copula/MCMC selection model and it is not individual-level MRMO for mixed continuous and binary responses. Those methods require different inputs, algorithms, and convergence diagnostics.

Numerical evidence

A frozen independent base-R generalized-least-squares fixture checks every coefficient, standard error, covariance element, multivariate Q, and joint Wald statistic. Tests also cover identity-correlation reduction to separate MVMR, random-effect inflation, deterministic PRESSO simulation, invalid matrices, and both command schemas.

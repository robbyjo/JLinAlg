Specify paths, estimate the implied covariance.

Observed-variable RAM structural models with free/fixed regressions, variances and covariances, equality constraints, Wald inference, and global fit indices.

Specify a mediation path

x → m → y
SemModel model = SemModel.builder("x", "m", "y")
    .regression("m", "x", .4)
    .regression("y", "m", .6)
    .variance("x", 1.0)
    .variance("m", .8)
    .variance("y", .5)
    .build();

The last number in each call is an optimizer start, not a fixed value. Use fixedRegression, fixedVariance, or fixedCovariance for known parameters.

Fit a sample covariance

Covariance ML
double[] covariance = {
    1.0, .5, .35,
    .5, 1.0, .70,
    .35, .70, 1.0
};

SemFitResult fit = Sem.fitCovariance(
    covariance, 2_000, model,
    SemOptions.defaults(),
    BackendPolicy.PREFERRED);

SemParameterEstimate path =
    fit.parameter("y~m");

The covariance is row-major and ordered exactly like model variables. Inspect convergence, parameter SE/z/p, implied covariance, likelihood chi-square, CFI, TLI, RMSEA, SRMR, AIC, and BIC.

Fit observed rows

Complete-case covariance ML
SemFitResult fromRows = Sem.fit(
    observedRows, model,
    new SemOptions(
        10_000, 1e-8,
        MissingDataPolicy.OMIT),
    BackendPolicy.PREFERRED);

Rows are observations and columns follow model variable order. OMIT uses complete-case covariance ML; it is not FIML.

Add equality constraints

Shared parameter label
SemModel constrained =
    SemModel.builder("x", "m", "y")
        .regression("equal", "m", "x", .4)
        .regression("equal", "y", "m", .4)
        .build();

Repeated labels share one free parameter. Fit indices need positive model DF; a just-identified model can reproduce the sample covariance by construction.

Current scopeThis is observed-variable covariance SEM. Latent measurement models, means, ordinal thresholds, robust corrections, modification indices, and FIML are not silently approximated.

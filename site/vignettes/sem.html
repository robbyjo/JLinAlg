Specify paths. Verify the implied covariance.

Continuous observed-variable RAM models with analytic maximum-likelihood gradients, expected-information inference, equality constraints, and global fit indices.

Validated and benchmarked in v0.2.0Paths, variances, exogenous and residual covariances, standard errors, likelihood, and fit indices are checked against lavaan 0.7-2. On the documented 4,680-row model, JLinAlg was 8.58x faster.

Statistical contract

JLinAlg uses the observed-variable RAM relationship Σ = (I − A)⁻¹ S (I − A)⁻ᵀ and multivariate-normal covariance-structure ML. A contains directed paths; S contains residual variances and covariances. Free variances are optimized on the log scale.

Specify a path model

Cardiometabolic path subset
SemModel model = SemModel.builder(
        "Age", "Sex", "BMI", "Waist", "Glucose")
    .regression("BMI", "Age", 0.1)
    .regression("BMI", "Sex", -0.1)
    .regression("Waist", "BMI", 0.7)
    .regression("Waist", "Sex", -0.1)
    .regression("Glucose", "Age", 0.1)
    .regression("Glucose", "BMI", 0.2)
    .covariance("Age", "Sex", 0.0)
    .variance("Age", 1.0)
    .variance("Sex", 1.0)
    .variance("BMI", 0.8)
    .variance("Waist", 0.3)
    .variance("Glucose", 0.8)
    .build();

The final numeric argument is an optimizer start. Use fixedRegression, fixedVariance, or fixedCovariance for known values. Omitted variances are added as free parameters with start 1.0.

Fit observed rows

Complete-case covariance ML
SemFitResult fit = Sem.fit(
    observedRows, model,
    new SemOptions(
        10_000, 1e-8,
        MissingDataPolicy.OMIT),
    BackendPolicy.PREFERRED);

if (!fit.converged()) {
    throw new IllegalStateException(
        "SEM did not converge");
}

Rows are observations and columns follow model variable order. OMIT selects one jointly complete sample, centers it, and forms the ML covariance with denominator N. It is not FIML. Standardize strongly mismatched scales before fitting.

Fit sufficient statistics

Dense row-major covariance
SemFitResult covarianceFit =
    Sem.fitCovariance(
        covariance, observations, model,
        SemOptions.defaults(),
        BackendPolicy.PREFERRED);

The covariance must be positive definite and ordered exactly like the model variables. Pass an ML covariance when exact row-data likelihood and fit-index parity is required.

Inspect parameters and fit

Wald and global fit
SemParameterEstimate path =
    fit.parameter("Waist~BMI");

System.out.printf(
    "beta=%g se=%g z=%g p=%g%n",
    path.estimate(),
    path.standardError(),
    path.zStatistic(),
    path.pValue());

System.out.printf(
    "chi2=%g df=%d CFI=%g RMSEA=%g%n",
    fit.chiSquare(),
    fit.degreesOfFreedom(),
    fit.cfi(), fit.rmsea());

The result also contains TLI, SRMR, log likelihood, AIC, BIC, implied covariance, sample size, optimizer evaluations, and backend provenance. Fit indices are informative only when model degrees of freedom are positive.

Equality constraints

Shared parameter label
SemModel equalPaths =
    SemModel.builder("x", "m", "y")
        .regression(
            "shared", "m", "x", .4)
        .regression(
            "shared", "y", "m", .4)
        .build();

Repeated labels share one free parameter. A label cannot mix variance and nonvariance parameters.

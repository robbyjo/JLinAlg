Five mediation effects, one common sample.

Fit Gaussian OLS, grouped-REML, or pedigree-REML mediation from an observation table using only the executable JAR.

Version availabilityThe mediation CLI command was added after v0.3.4. Use current jlinalg-0.3.5-SNAPSHOT.jar or a later release; it is not present in the published v0.3.4 JAR.
Shell syntaxWebsite command blocks use the POSIX-shell \ line continuation. In PowerShell replace it with a backtick or put the command on one line.

1. State the model

M = intercept + a X + alpha C + error
Y = intercept + direct X + b M + gamma C + error
Y = intercept + total X + delta C + error
indirect = a * b

The input is observation-by-variable CSV/TSV. Outcome Y, treatment X, mediator M, and selected covariates must be numeric. Encode categorical covariates as numeric indicators; do not add an intercept.

sample_id,treatment,mediator,outcome,age,sex01,subject

O002,0.8,1.7,3.9,48,1,P002
O003,1.1,2.2,4.7,61,0,P003

2. Ordinary mediation

Gaussian OLS mediation
java -jar jlinalg-<version>.jar mediation --input mediation.csv \
  --outcome outcome --treatment treatment --mediator mediator \
  --covariates age,sex01 --confidence 0.95 \
  --out mediation-effects.csv

One complete-case sample is used for all three component fits. Missing outcome, treatment, mediator, or selected covariate rows are omitted and counted.

3. Read the five effects

  • a: treatment to mediator.
  • b: mediator to outcome adjusted for treatment.
  • indirect: product a x b.
  • direct: treatment effect in the outcome model containing M.
  • total: treatment effect in the outcome model without M.

Each row reports estimate, SE, statistic, p-value, confidence limits, and degrees of freedom. The indirect SE is the first-order Sobel value sqrt(b^2 Var(a) + a^2 Var(b)) with normal inference. There is no bootstrap, simulation, or posterior sampling.

4. Repeated observations and clusters

Grouped REML mediation
java -jar jlinalg-<version>.jar mediation --input repeated.tsv \
  --outcome outcome --treatment treatment --mediator mediator \
  --covariates age,sex01 --group subject \
  --out mediation-subject-reml.tsv

The same sparse random-intercept structure enters all three component models. Repeat --group or pass comma-separated columns for multiple independent random intercepts. Check converged=true in the log.

Pedigree REML mediation
java -jar jlinalg-<version>.jar mediation --input mediation-pedigree.csv \
  --outcome outcome --treatment treatment --mediator mediator \
  --covariates age --individual-id subject \
  --pedigree pedigree.csv --pedigree-id member_id \
  --sire-id parent1_id --dam-id parent2_id \
  --out mediation-pedigree.tsv

Blank, NA, 0, ., and -9 parent values mean unknown. If the family column is used, known analysis IDs must be qualified as family_id:member_id, such as F10:1003; omit it when IDs are globally unique.

Subject 9009 is absent from the pedigree, so it becomes a reported unrelated singleton. Repeated rows with the same absent ID share one founder and random effect. Add ordinary effects such as --group clinic alongside pedigree relatedness when needed.

6. Outputs and interpretation

--out mediation-effects.csv writes the five-row result and mediation-effects.csv.log. The log records model type, variables, covariates/groups, input and retained rows, pedigree singleton counts, confidence, backend, and convergence. Output suffix controls CSV versus TSV; existing files require --overwrite.

Causal assumptions remain scientific assumptionsAssess treatment-outcome, treatment-mediator, and mediator-outcome confounding, temporal order, measurement error, and model form. Sobel inference assumes zero cross-model covariance between a and b. This is not a correlated-equation, random-slope, or general multilevel causal mediation model.

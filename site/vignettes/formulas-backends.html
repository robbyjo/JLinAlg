Compile the model once. Route the algebra deliberately.

Use an R-like layer for model construction without putting parsing, factor discovery, or contrast allocation inside the numerical hot path.

Compile a fixed formula

Treatment contrasts and interaction
ModelTable table = ModelTable.builder(6)
    .numeric("y", 11, 13, 15, 17, 19, 21)
    .numeric("x", 0, 1, 2, 3, 4, 5)
    .numeric("logExposure", 0, 0, 0, 0, 0, 0)
    .numeric("w", 1, 2, 1, 2, 1, 2)
    .categorical("sex", "F", "M", "F", "M", "F", "M")
    .build();

CompiledFormula compiled = Formula.compile(
    "y ~ x * sex + offset(logExposure)",
    table,
    new FormulaOptions(
        ContrastCoding.TREATMENT, "w"));

OlsResult fit = compiled.fitOls(
    OlsOptions.defaults(), BackendPolicy.PREFERRED);

Use sum contrasts when needed. The compiled model owns contiguous response/design/weight/offset arrays and can fit OLS or GLM without reparsing.

Compile mixed syntax

Independent and nested terms
ModelTable repeatedTable = ModelTable.builder(6)
    .numeric("y", 4.1, 4.7, 5.0, 5.4, 6.0, 6.3)
    .numeric("age", 20, 22, 25, 31, 34, 38)
    .categorical("site", "A", "A", "A", "B", "B", "B")
    .categorical("subject", "1", "1", "2", "3", "3", "4")
    .build();

CompiledMixedFormula mixed = MixedFormula.compile(
    "y ~ age + (1 + age || site) + " +
    "(1 | subject)", repeatedTable);

SparseLinearMixedModelResult sparse =
    mixed.fitSparse(
        RemlOptions.builder()
            .initialVariances(1, 1, 1, 1)
            .build(),
        BackendPolicy.PREFERRED);

Double-bar expands independent intercept and slope terms. (1 | site/subject) expands site and site:subject. Single-bar correlated blocks use the dense correlated fitter.

Select a backend policy

PREFERRED tries GPU automatic routing, oneMKL, OpenBLAS, then portable Java CPU. Results record the concrete provider and device.

Provider provenance
OlsResult fit = Ols.fit(
    y, x, OlsOptions.defaults(),
    BackendPolicy.PREFERRED);

System.out.println(
    fit.backend().selectedBackend());
System.out.println(
    fit.backend().deviceDescription());

Strict CUDA, OpenCL, Vulkan, oneMKL, OpenBLAS, GPU, and CPU policies fail clearly when unavailable. They do not silently select another provider.

Avoid nested oversubscription

Start with one accelerator submitterGPU and native BLAS already parallelize kernels. Use acceleratedSerial() first. Use cpuParallel() when outer Java workers should own parallelism.

Benchmark the target machine

PowerShell
.\gradlew.bat benchmarkAssociation
.\gradlew.bat benchmarkMixedModels

Compare warm runs with identical models/tolerances and record provider/device. Sparse structure can matter more than peak dense FLOPS.

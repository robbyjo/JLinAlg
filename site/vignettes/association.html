Prepared scans factor a shared null model once. Exact adapters refit any supported model with bounded parallelism. Both preserve input order and complete association output.

Fast OLS marker scan

Residualized marker blocks
AssociationEngineOptions execution =
    AssociationEngineOptions.cpuParallel()
        .withParallelism(8)
        .withChunkSize(256);

AssociationBatchResult scan =
    FastOlsAssociation.scanPredictors(
        phenotype, covariates, dosages,
        markerNames, null, null,
        OlsOptions.defaults(), execution);

AssociationEstimate hit = scan.estimate(0);

Fast OLS uses Frisch–Waugh–Lovell residualization and factors the shared covariates once. Rows are samples; candidate columns are markers or molecular features.

Prepare a P3D/EMMAX REML scan

Frozen variance components
RemlAssociationScanner mixed =
    RemlAssociationScanner.prepare(
        phenotype, covariates, components,
        RemlOptions.defaults(),
        BackendPolicy.PREFERRED);

AssociationScanResult p3d = mixed.scan(
    rowMajorDosages, markerCount, markerNames,
    new AssociationScanOptions(
        2048, GenotypeMissingPolicy.MEAN_IMPUTE, 1));

This estimates variance components once and reuses the GLS projection. It is the explicit P3D/EMMAX approximation, not per-marker REML.

Run exact parallel refits

Any association adapter
AssociationFitter model =
    AssociationModels.sparseLinearMixedModel(
        randomTerms, RemlOptions.defaults());

AssociationBatchResult exact =
    ParallelAssociationEngine.scanPredictors(
        phenotype, covariates, dosages,
        markerNames, model, execution);

Adapters cover OLS, GLM, dense/sparse/correlated LMM, REML, pedigree, GLMM PQL, ridge, and ARIMA-error LMM. Use RECORD_NAN to retain structured failures in long scans.

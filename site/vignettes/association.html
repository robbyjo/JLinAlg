Stream the cohort. Reuse the model.

Read modern genotype formats in bounded blocks, compute QC after sample alignment, transform omics matrices, and reuse prepared OLS or mixed-model nulls across millions of tests.

Open and filter a cohort

VCF, BCF, or BGEN
VariantSource source = VariantSources.open(
    Path.of("cohort.vcf.gz"));

VariantFilterOptions qc = VariantFilterOptions.builder()
    .minimumMac(20).minimumMaf(0.005)
    .maximumMissingRate(0.02)
    .minimumImputationQuality(0.8).build();

AssociationPipelineOptions pipeline =
    new AssociationPipelineOptions(4096, qc);

CSV, TSV, VCF, VCF.gz, BCF, and biallelic layout-2 BGEN are supported; PLINK is intentionally omitted. Samples are matched and reordered before MAC, MAF, missingness, and quality filters are calculated.

Stream results to disk

Bounded input and output
try (DelimitedAssociationWriter output =
        new DelimitedAssociationWriter(
            Path.of("gwas.tsv"), '\t')) {
    StreamingAssociationPipeline.fastOlsTo(
        source, analysisSampleIds, phenotype,
        covariates, null, null,
        OlsOptions.defaults(), execution,
        pipeline, output);
}

The same ordered table records tested estimates, cohort QC, exclusions, and structured failures. Use remlP3dTo with a retained RemlAssociationScanner for related samples.

Fast OLS marker scan

Residualized marker blocks
AssociationEngineOptions execution =
    AssociationEngineOptions.cpuParallel()
        .withParallelism(8)
        .withChunkSize(256);

AssociationBatchResult scan =
    FastOlsAssociation.scanPredictors(
        phenotype, covariates, dosages,
        markerNames, null, null,
        OlsOptions.defaults(), execution);

AssociationEstimate hit = scan.estimate(0);

Fast OLS uses Frisch–Waugh–Lovell residualization and factors the shared covariates once. Rows are samples; candidate columns are markers or molecular features.

Prepare a P3D/EMMAX REML scan

Frozen variance components
RemlAssociationScanner mixed =
    RemlAssociationScanner.prepare(
        phenotype, covariates, components,
        RemlOptions.defaults(),
        BackendPolicy.PREFERRED);

AssociationScanResult p3d = mixed.scan(
    rowMajorDosages, markerCount, markerNames,
    new AssociationScanOptions(
        2048, GenotypeMissingPolicy.MEAN_IMPUTE, 1));

This estimates variance components once and reuses the GLS projection. It is the explicit P3D/EMMAX approximation, not per-marker REML.

Run exact parallel refits

Any association adapter
AssociationFitter model =
    AssociationModels.sparseLinearMixedModel(
        randomTerms, RemlOptions.defaults());

AssociationBatchResult exact =
    ParallelAssociationEngine.scanPredictors(
        phenotype, covariates, dosages,
        markerNames, model, execution);

Adapters cover OLS, GLM, dense/sparse/correlated LMM, REML, pedigree, GLMM PQL, ridge, and ARIMA-error LMM. Use RECORD_NAN to retain structured failures in long scans.

Transform molecular features

TWAS, EWAS, or PWAS
OmicsTransform transform = OmicsTransforms.compose(
    OmicsTransforms.winsorize(0.01, 0.99),
    OmicsTransforms.rankInverseNormal());

OmicsAssociationResult traits =
    StreamingOmicsAssociationPipeline.scanResponses(
        matrix, analysisSampleIds, design,
        testedCoefficient, transform,
        OmicsMissingPolicy.MEAN_IMPUTE, 512,
        null, null, OlsOptions.defaults(), execution);

Identity, Winsorization, log, shifted log, z-score, and tie-aware Blom inverse-normal transforms compose without mutating source rows.

Test rare-variant sets

Burden, SKAT, and SKAT-O
LinearSetTestNullModel nullModel =
    LinearSetTestNullModel.prepare(
        phenotype, covariates,
        OlsOptions.defaults(), BackendPolicy.PREFERRED);

SetTestResult burden = SetTests.burden(
    gene, nullModel, SetTestOptions.defaults());
SetTestResult skat = SetTests.skat(
    gene, nullModel, SetTestOptions.defaults());
SkatOResult skatO = SetTests.skatO(
    gene, nullModel, SetTestOptions.defaults());

Effect-allele orientation and QC are explicit. Wrap the retained mixed scanner in RemlSetTestNullModel to run related-sample Burden/SKAT/SKAT-O without another REML fit per gene.

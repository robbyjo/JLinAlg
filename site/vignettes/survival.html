Hazard ratios with the risk set made explicit.

Fit fixed Cox models, Gaussian shared frailty, or pedigree-correlated frailty from the same Efron/Breslow partial-likelihood core.

Encode follow-up

Right-censored or start-stop
CoxSurvivalData right =
    CoxSurvivalData.rightCensored(
        followUpTime, observedEvent);

CoxSurvivalData delayed =
    new CoxSurvivalData(
        entry, exit, observedEvent, strata);

Rows are at risk when start < t <= stop. Strata have separate baseline hazards. Do not include an intercept in the Cox covariate matrix.

Fit a fixed Cox model

Efron ties
CoxResult fit = CoxRegression.fit(
    right, covariates, offset,
    CoxOptions.defaults()
        .withTies(CoxTies.EFRON),
    BackendPolicy.PREFERRED);

double hr = fit.hazardRatios()[0];
double se = fit.standardErrors()[0];
double p = fit.pValues()[0];

Outputs include beta, hazard ratio, SE, z, ordinary and −log₁₀ p-values, hazard-ratio confidence intervals, convergence, backend provenance, and baseline cumulative hazard/survival.

Add Gaussian shared frailty

Laplace-profiled variance
CoxRandomEffectTerm center =
    CoxRandomEffectTerm.independent(
        RandomEffectTerm.randomIntercept(
            "center", centerIds));

CoxMixedResult mixed = CoxMixedModel.fit(
    right, covariates, List.of(center));

double variance = mixed
    .randomEffects("center").variance();

Conditional modes maximize penalized partial likelihood. Frailty variances use a Laplace-approximated marginal partial likelihood—not REML. Several independent or caller-precision Gaussian terms may be combined.

Use pedigree-correlated frailty

Additive A-inverse precision
CoxPedigreeResult pedigreeFit =
    CoxPedigreeFrailty.fit(
        right, covariates,
        observationAnimalIds, pedigree);

double geneticVariance =
    pedigreeFit.frailtyVariance();
double mode = pedigreeFit
    .frailty("offspring");

The pedigree facade uses directly constructed A⁻¹ and returns named modes for every pedigree member, including unobserved ancestors retained in the coefficient system.

Current boundaryThe fixed right-censored risk pass is sorted and linear after setup. Start-stop data use the general reference path. Mixed/pedigree random information is currently dense; robust sandwich inference, PH diagnostics, gamma frailty, and sparse large-pedigree Cox solves remain planned.

Fit fixed Cox models, Gaussian shared frailty, empirical-GRM kinship, or pedigree-correlated frailty from the same Efron/Breslow partial-likelihood core.

CLI-only Cox workflows

Fixed Cox model
java -jar jlinalg-0.3.3.jar --pheno phenotype.csv --id SampleName --formula "Surv(followup,event) ~ Sex + Age" --ties efron --out cox.csv
GRM kinship frailty
java -jar jlinalg-0.3.3.jar --pheno phenotype.csv --id SampleName --individual-id IID --formula "Surv(followup,event) ~ Sex + Age" --grm cohort --ties efron --out cox-grm.csv

The general CLI supports right-censored Cox models and Gaussian GRM kinship frailty. Streamed <omics> Cox scans, start-stop intervals, strata, ordinary formula frailty, and pedigree-correlated Cox models shown below remain Java APIs.

Encode follow-up

Right-censored or start-stop
CoxSurvivalData right =
    CoxSurvivalData.rightCensored(
        followUpTime, observedEvent);

CoxSurvivalData delayed =
    new CoxSurvivalData(
        entry, exit, observedEvent, strata);

Rows are at risk when start < t <= stop. Strata have separate baseline hazards. Do not include an intercept in the Cox covariate matrix.

Fit a fixed Cox model

Efron ties
CoxResult fit = CoxRegression.fit(
    right, covariates, offset,
    CoxOptions.defaults()
        .withTies(CoxTies.EFRON),
    BackendPolicy.PREFERRED);

double hr = fit.hazardRatios()[0];
double se = fit.standardErrors()[0];
double p = fit.pValues()[0];

Outputs include beta, hazard ratio, SE, z, ordinary and −log₁₀ p-values, hazard-ratio confidence intervals, convergence, backend provenance, and baseline cumulative hazard/survival. Start-stop rows use an indexed event-time sweep.

Diagnostics and prepared scans

CoxDiagnosticsResult diagnostics = CoxDiagnostics.analyze(
    survival, covariates, fit, offset, subjectIds);
FastCoxAssociation scan = FastCoxAssociation.prepare(
    survival, covariates, offset, options, engineOptions);

Cluster-robust covariance supports repeated start-stop rows. Martingale, deviance, score, dfbeta, and Schoenfeld residuals are exported with per-term and global proportional-hazards tests. Prepared score scans reuse one null fit and risk-set plan.

Shared gamma frailty

CoxGammaFrailtyResult gamma = CoxGammaFrailty.fitAtVariance(
    survival, covariates, centerIds, offset, 0.2,
    CoxGammaFrailtyOptions.defaults(), BackendPolicy.PREFERRED);

The multiplicative gamma frailty has mean one and variance theta. Fixed-theta estimates match R survival references; optional variance profiling uses an explicit Laplace approximation.

Add Gaussian shared frailty

Laplace-profiled variance
CoxRandomEffectTerm center =
    CoxRandomEffectTerm.independent(
        RandomEffectTerm.randomIntercept(
            "center", centerIds));

CoxMixedResult mixed = CoxMixedModel.fit(
    right, covariates, List.of(center));

double variance = mixed
    .randomEffects("center").variance();

Conditional modes maximize penalized partial likelihood. Frailty variances use a Laplace-approximated marginal partial likelihood—not REML. Several independent or caller-precision Gaussian terms may be combined.

Adjust for cryptic relatedness

Empirical GRM frailty
GenomicRelationshipMatrix grm =
    GenomicRelationshipMatrix.fromVariants(
        relationshipVariants, sampleIds,
        GenomicRelationshipOptions.defaults(),
        BackendPolicy.PREFERRED);

CoxMixedResult relatedFit =
    CoxKinshipFrailty.fit(
        right, covariates,
        observationSampleIds, grm);

The GRM is converted to named Gaussian precision internally. Repeated start-stop rows may map to the same sample. Explicit diagonal regularization handles duplicate samples and finite-marker rank.

Use pedigree-correlated frailty

Additive A-inverse precision
PedigreeRandomEffectTerm sparseTerm =
    PedigreeRandomEffectTerm.ofSparse(
        "pedigree", observationAnimalIds,
        pedigreeEntries, inbreedingCoefficients);

CoxPedigreeResult pedigreeFit =
    CoxPedigreeFrailty.fitSparse(
        right, covariates, sparseTerm);

double geneticVariance =
    pedigreeFit.frailtyVariance();
double mode = pedigreeFit
    .frailty("offspring");

A term built with ofSparse or justified ofUninbred avoids dense pedigree covariance end to end. The sparse facade supports repeated rows per individual and returns named modes for every pedigree member, including unobserved ancestors. Results expose solver type, sparse equation/factor nonzeros, convergence, boundary singularity, and backend provenance.

Current boundaryThe sparse path requires one-stratum right-censored data with distinct event times and unit incidence. It keeps the exact penalized score but uses a diagonal approximation to profiled random-effect information, so Laplace variance and covariance can differ from the dense fit. Cases needing exact dense frailty information should use the general path.

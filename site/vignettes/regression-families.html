Regression families

Multivariate, multinomial, quantile, kernel, supersmoother, and partially linear models.

Shared-design Gaussian and multinomial regression

var gaussian = MultivariateRegression.fit(responseMatrix, design);
var classes = MultinomialRegression.fit(labels, design, 3);

Multivariate OLS reuses one pivoted QR and returns outcome-major coefficients and residual covariance. Multinomial logistic regression uses class 0 as baseline, stable log likelihood, scaled optimization, and score-based convergence. Inspect the convergence flag.

Quantile, kernel, and supersmoother

var median = QuantileRegression.fitExact(y, design, 0.5);
var kernel = KernelRegression.fit(x, y);
var smooth = SuperSmoother.fit(x, y);

The fitExact API solves the nonsmoothed pinball linear program with primal/dual optimality checks. The compatibility fit API retains smoothed loss; its benchmark is separate. Gaussian Nadaraya–Watson regression uses fixed or rule-of-thumb bandwidth and stable normalized weights. Supersmoothing implements R's running-window algorithm with local cross-validation, weighted/bass, fixed-span, and periodic options. Predictions interpolate the fitted curve with constant extrapolation and do not depend on query-batch ordering.

Partially linear regression

var inference = PartiallyLinearRegression.fitWithInference(
    y, linearDesign, z, 0.5, BackendPolicy.CPU);

Robinson residualization removes smooth effects from the response and linear predictors, fits slopes, and reports smoother-aware HC3-style and homoskedastic slope covariance. Smooth centering identifies the intercept. The slope requires conditional predictor variation; fixed-bandwidth smoothing bias and dependent rows need substantive review. Intercept normalization is not covered by slope covariance. Generalized HC3 is asymptotic and may be conservative at high smoothing leverage.

Independent accuracy checks

A 1,006-value R fixture covers lm, nnet, quantreg plus matching smoothed optimization, explicit kernel algebra, stats::supsmu, Robinson HC3, and glmnet/selectiveInference. Tests also exercise scaled multinomial designs, kernel underflow, ties, extrapolation, weighted selection, and conditional calibration.

Home/Vignettes/Regression families

Six regression families, one explicit numerical contract.

Deterministic Java APIs for multivariate Gaussian, multinomial, quantile, kernel, supersmoother, and partially linear analyses.

ScopeThese are in-memory APIs with no bootstrap or Monte Carlo sampling. R-like names identify the reference family; they do not imply byte-for-byte optimizer or edge-behavior parity.

Multivariate and multinomial models

MultivariateRegressionResult gaussian = MultivariateRegression.fit(responseMatrix, design); MultinomialRegressionResult classes = MultinomialRegression.fit(labels, design, 3);

Multivariate OLS fits one shared-design least-squares system per response and returns outcome-major coefficients plus residual covariance. Multinomial logistic regression uses class 0 as the baseline, monotone line search, and normalized fitted probabilities. Inspect the likelihood and convergence metadata.

Quantile, nonparametric, and smooth models

QuantileRegressionResult median = QuantileRegression.fit(y, design, 0.5); KernelRegression.Result kernel = KernelRegression.fit(x, y); SuperSmoother.Result smooth = SuperSmoother.fit(x, y);

Quantile regression minimizes a smoothed pinball loss. Kernel regression uses Gaussian Nadaraya–Watson weights with an explicit or Silverman-style bandwidth. The supersmoother selects among candidate spans using leave-one-out local-linear tricube fits and exposes the selected spans.

Partially linear semiparametric regression

PartiallyLinearRegression.Result fit = PartiallyLinearRegression.fit(y, linearDesign, z, 0.5); double[] beta = fit.coefficients(); double[] g = fit.smoothEffect();

The model is y = X beta + g(z) + error, alternating QR-backed least-squares updates with kernel updates. The result includes the smooth effect, residuals, iteration count, and convergence flag.

Accuracy and speed

Run ./gradlew test --tests org.jlinalg.regression.RegressionFamiliesTest for coefficient recovery, probability normalization, and finite-output checks. Run ./gradlew benchmarkRegressionFamilies for median JVM timings and rows per second across all six paths. Direct R timing is not reported for this release because Rscript was not installed on the development host; use identical data and warm-up policy before comparing to lm/rrr, nnet::multinom, stats::supsmu, quantreg, or np/npreg.

Align alleles before estimating causes.

A worked summary-data flow from structured harmonization exclusions through core, LD-aware, robust, multivariable, and overlap-sensitive estimators.

Harmonize summary associations

Exposure and outcome
SummaryAssociation exposure =
    new SummaryAssociation(
        "rs1", "A", "C", .10, .02, .20);
SummaryAssociation outcome =
    new SummaryAssociation(
        "rs1", "A", "C", .05, .02, .21);

HarmonizationResult aligned =
    AlleleHarmonizer.harmonize(
        exposureStats, outcomeStats,
        HarmonizationOptions.defaults());

System.out.println(aligned.exclusions());

Palindromic variants require frequencies that select exactly one orientation. Missing, duplicate, incompatible, frequency-inconsistent, and zero-exposure variants carry structured exclusions.

Run the core estimator set

IVW, Egger, median, leave-one-out
MrAnalysisResult mr =
    MendelianRandomization.analyze(
        aligned.instruments(),
        new MrOptions(.95, 10_000, 20260901L));

MrEstimate fixed = mr.ivwFixed();
MrEstimate random =
    mr.ivwMultiplicativeRandom();
MrEggerResult egger = mr.egger();

Inspect Cochran Q/I², Egger intercept, I²GX, mean F statistic, leave-one-out results, and warnings—not only the smallest p-value.

Retain correlated instruments

Generalized IVW
CorrelatedMrEstimate generalized =
    CorrelatedMendelianRandomization.ivw(
        aligned.instruments(), alleleAlignedLd, true);

CorrelatedMrEggerResult ldEgger =
    CorrelatedMendelianRandomization.egger(
        aligned.instruments(), alleleAlignedLd);

LD row/column signs and order must match the harmonized exposure effect alleles. Prune or scientifically regularize a nearly singular matrix first.

Add direction and robustness checks

Sensitivity suite
SteigerResult steiger = SteigerFiltering.analyze(
    aligned.instruments(), nExposure, nOutcome);
MrRapsResult raps =
    RobustMendelianRandomization.raps(
        aligned.instruments());
MrPressoResult presso = MrPresso.analyze(
    aligned.instruments(), .05);
ContaminationMixtureResult mixture =
    ContaminationMixture.fit(
        aligned.instruments(), 1001);
Estimator scopeThe PRESSO-style path is an analytic robust-center/outlier diagnostic, not the R package's simulation calibration. Robustness checks do not validate the exclusion restriction.

Multivariable and overlap-aware MR

Direct effects and sampling covariance
MultivariableMrResult direct =
    MultivariableMendelianRandomization.ivw(
        instruments, List.of("LDL", "HDL"));
OverlapAwareMrResult overlap =
    OverlapAwareMendelianRandomization.ivw(
        aligned.instruments(),
        exposureOutcomeCovariance);

The overlap input is per-instrument sampling covariance, not overlap percentage. Preserve original and winner's-curse-corrected exposure analyses as sensitivity results.

Performance by design

Reuse the expensive part.

Fast paths are explicit about what is cached and which estimator they return.

Prepared GWAS scan
RemlAssociationScanner prepared =
    RemlAssociationScanner.prepare(
        phenotype, covariates, components,
        RemlOptions.defaults(),
        BackendPolicy.PREFERRED);

AssociationScanResult scan = prepared.scan(
    dosages, markerCount, markerNames,
    AssociationScanOptions.defaults());

One null fit. Many tests.

The P3D/EMMAX path estimates variance components once and caches its GLS projection. Fast OLS factors covariates once. Fast GLM keeps the final IRLS metric. Exact parallel adapters remain available when approximation is not acceptable.

Default routingGPU when available, then oneMKL, OpenBLAS, and portable CPU. Strict policies fail clearly instead of silently changing providers.

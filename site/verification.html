Checked for accuracy. Measured for speed.

Every shipped component family has automated correctness coverage and an executable performance route. Comparative claims below are real workload measurements with estimator scope and limitations preserved.

What “checked” meansCorrectness is gated by unit, contract, cross-backend, and independent R/Python fixtures. Performance is exercised by deterministic or real-data benchmarks. A benchmark check does not imply that every API is faster than every alternative.

The clean v0.2.0 release gate discovered 253 tests: 250 passed, zero failed, and three optional CHOLMOD-native tests were skipped because the native library was not staged in that portable build. The separately documented native profiles cover CHOLMOD on the development host.

SEM numerical result

On 4,680 complete TOPMed rows and a 36-parameter observed-variable model, JLinAlg and lavaan printed the same log likelihood (-70763.3172885), chi-square (4497.68284338), CFI (0.799908468824), TLI (0.685570451009), and RMSEA (0.150559985169). Maximum absolute parameter and SE differences were below 1e-8 and 5e-10. SRMR was 0.0855176490074 versus 0.0855176482142.

The model's CFI/RMSEA indicate poor substantive fit; equality between engines establishes numerical parity, not biological validity. Read the SEM vignette and full path specification →

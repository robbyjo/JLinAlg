# Adaptive random-intercept quadrature verification

Run date: 2026-09-08, Windows, Java 25, R 4.6.1, lme4 2.0.6.
No full-project build was used during concurrent package repairs. Production
and benchmark sources compiled with `javac -Xlint:all -Werror` against existing
main classes and JDistlib into `build/quadrature-classes`.

Eight fixed-parameter fixtures use R `integrate`, splitting at the posterior
mode and shifting the log integrand to avoid missed narrow peaks/underflow.
Absolute Java errors were below 1e-12. Four independently generated datasets
(384 observations, 32 groups, intercept and slope, nonzero offsets) compare
full marginal ML fits to `glmer(nAGQ=25)`. Fixed-effect errors are below 4e-7,
SD errors below 4e-7, and standard-error errors below 6e-7. The entire joint
covariance, including variance nuisance uncertainty, is tested against the
transformed inverse lme4 observed Hessian. Frozen TSV/properties files and the
R generator are under `src/test/resources/r-reference/quadrature-*`.

The audit's ordered 100-observation 50/50 Bernoulli likelihood at beta=0, sd=1
is -70.94145611404414 (Java and R), versus the old fixed-ten-node result
-72.5979927915. Adaptation needs 19 nodes for this case; the all-zero group with
sd=3 needs up to 257 for two successful refinement checks at tolerance 1e-10.

## Full-fit timing, same accuracy gate

Both programs preload the same datasets, run three warmups, and report the
median of seven fits. Each timed fit includes fixed-effect inference. Java
uses default adaptive convergence controls; R uses nAGQ=25, bobyqa, and its
default derivative checks. Every fit must meet coefficient/SD/SE tolerances
1e-5 and full-likelihood tolerance 2e-6 against frozen references. R's
count-specific deviance constant is corrected outside its timer using the
independent full-integral fixture. Both consume fitted results in a checksum.

| Dataset | Java median seconds | R median seconds | Java full LL error |
| --- | ---: | ---: | ---: |
| Bernoulli | 0.111397 | 0.080000 | 8.53e-14 |
| Rare Bernoulli | 0.208816 | 0.110000 | 2.84e-14 |
| Binomial counts | 0.129154 | 0.130000 | 3.41e-13 |
| Poisson counts | 0.069338 | 0.110000 | 1.34e-11 |

These are small-fixture timings on a shared development host, not universal
speed claims. Java is slower on binary/rare data, effectively tied on this
binomial-count fixture, and faster on this Poisson fixture. These measurements
were regenerated after the four independent-review repairs below. R elapsed
timings have only approximately 0.01-second resolution
on this host. Java includes stricter integration checks, multiple optimization
starts and the zero-variance comparison; lme4 uses its own fitting strategy.

Reproduce (from repository root, with benchmark classes compiled):

```powershell
java -cp 'build/quadrature-classes;build/classes/java/main;build/dependencies/jdistlib-all-0.10.1.jar' org.jlinalg.benchmark.GlmmQuadratureBenchmark
```

start with `.libPaths(c('build/r-library', .libPaths()))`. Dependencies were
already installed and no new installs were needed for the successful runs.

## Independent-review counterexamples

All 13 quadrature JUnit tests pass in the isolated build. Additional frozen
base-R references are generated by
`src/test/resources/r-reference/generate-quadrature-stress-reference.R`:

* For two groups with 3,000,000 binomial trials and successes 1,500,000 +/- 1,225,
  the right NLL variance derivative is -750625, not the positive sign produced
  by the old absolute 1e-5 stencil. The analytic boundary score and scaled
  `log1p(variance/v0)` optimization recover variance 1.33444554e-6 and LL
  -17.0592688954 (zero-variance LL -17.3665386074), with intercept SE
  0.00115494141 and variance covariance 7.11704920e-12. The shallower review
  case (300,000 trials, imbalance 287) recovers variance 1.31004975e-6 and
  LL -14.1568401578, improving the boundary by 0.00453231. A concentration
  grid also guards against false boundary success.
* Stable Stirling-error/deviance evaluation matches R `dbinom`/`dpois` through
  counts of 1e16 within 2e-11. The balanced binomial log mass is now
  -18.6464720965971 instead of the impossible positive 35; Poisson is
  -19.3396192771570. Tests span both sides of the small-count formula threshold.
* The valid proportion 186369615/354343171 is accepted with ULP-aware
  reconstruction; its MLE log mass is -10.06733010709238. Clearly fractional
  reconstructed counts and noninteger Bernoulli/Poisson responses are rejected.
* Bracket-contraction safeguards resolve Poisson offsets 100, 300, 500, and
  1000. Their likelihoods match mode-centered R integration within 2e-9;
  at offset 1000 the finite LL is -494112.62937676522.

Covariance tests use the full observed marginal likelihood information with
the optimization-coordinate Jacobian, not a conditional plug-in covariance.
The two-group examples test numerical correctness, not finite-sample Wald
coverage. Node refinement is not a bound on arithmetic roundoff in extreme data.

## Actual limits

Independent scalar Gaussian random intercepts only; no pedigree GH, correlated
random slopes, crossed random effects, negative binomial, or estimated
dispersion. Integration is numerical with a refinement-based error estimate,
not a certified exact integral. Positive definite joint Hessian and small score
are required for interior Wald inference. At variance zero, only the
fixed-effect covariance conditional on that boundary is available. No global
optimization certificate or exact finite-sample inference is claimed.

# Rare-variant reference fixtures

`STUDY*.QT1.*`, `STUDY*.rvtests.*`, `group.file`, and `COMBINED.QT1.*` are test
data/reference outputs from statgen/raremetal v4.15.1, commit
`2c82cfc5710dbd9fd56ef67a7ca5f74772d4e70d`:

- `tests/raremetal/test_tut_rm/inputs` and `expected`
- `tests/raremetal/test_tut_rm_rvt_cov/inputs`
- https://github.com/statgen/raremetal/tree/v4.15.1/tests/raremetal

The source attribution is Shuang Feng, Dajiang Liu, Sai Chen, and Goncalo
Abecasis / statgen. No upstream statistical implementation was copied.
Reference output is rounded; tests use tolerances appropriate to that precision.
Historical malformed unknown-ALT rows are deliberately excluded, not treated as
valid associations. Reference allele orientation is aligned before comparing beta.

`independent-scores.tsv` is generated by
`src/benchmark/r/rare_meta_reference.R` using R SKAT and CompQuadForm, with
independent spherical integration of rank-three Gaussian quadratic-form tails.
`R-session.txt` records the generating versions. The tail fixture demonstrates
why a zero Davies return or cancellation-prone Imhof tail is not an accuracy
oracle: the independent survival integral remains positive near 1.06e-22.
SKAT-O's moment-based R output and correlated Gaussian simulation are compared
only at resolvable moderate probabilities, not claimed identical algorithms.

`advanced-reference.R` generates `advanced-skato.tsv`, `advanced-vt.txt`,
`noncentral-tail.tsv`, and `noncentral-mixture.tsv` using base R 4.6.1. These are
original synthetic fixtures, not copied study data. SKAT-O uses direct polar
integration for rank two and an independent chi-square convolution for rank
three. The smallest adjusted fixture p is about 9.01633e-21. The noncentral
rank-one reference uses the exact sum of normal tails because R's noncentral
`pchisq` loses relative accuracy in some tested upper tails. The unequal
noncentral mixture reference integrates normal coordinates directly. Neither
reference implements the Java conditional positive-gamma-series algorithm.

# ACAT reference fixtures

`reference.tsv` is generated by `src/test/R/acat-reference.R` with R 4.6.1
and CompQuadForm 1.4.4. The script follows the public `yaowuliu/ACAT`
implementation for ACAT and ACAT-V, including the MAC <= 10 collapse and the
Beta(1,25)/Beta(1,1) weighting formulas. It uses CompQuadForm's Davies method
for the two independent SKAT reference tails and combines the six published
components with equal-weight ACAT to obtain ACAT-O.

Regenerate from the repository root:

```powershell
& 'C:\Program Files\R\R-4.6.1\bin\Rscript.exe' src/test/R/acat-reference.R src/test/resources/acat/reference.tsv C:/path/to/R/library
```

The R package is needed only to regenerate the checked-in fixture. Gradle tests
do not require R.

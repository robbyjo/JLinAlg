# R reference validation

The `RReferenceTest` suite protects numerical compatibility with independent R
implementations. Expected values were generated by
`src/test/resources/r-reference/generate-reference.R`; R is not invoked by the
Gradle build and is not a JLinAlg dependency.

## Reference environment

The committed fixtures were generated on 2026-08-31 with:

- R 4.6.1;
- `stats` 4.6.1;
- `nlme` 3.1-169;
- `rrBLUP` 4.6.3;
- `MendelianRandomization` 0.10.0.

The source examples and contracts are documented by
[base R `lm`](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/lm.html),
[base R `glm`](https://stat.ethz.ch/R-manual/R-devel/library/stats/html/glm.html),
[`nlme::lme`](https://stat.ethz.ch/R-manual/R-devel/library/nlme/html/lme.html),
[`rrBLUP::mixed.solve`](https://cran.r-project.org/web/packages/rrBLUP/rrBLUP.pdf),
and the CRAN
[`MendelianRandomization` manual](https://cran.r-project.org/web/packages/MendelianRandomization/MendelianRandomization.pdf).

## Cases covered

| JLinAlg path | R reference | Data and quantities compared |
| --- | --- | --- |
| OLS | `stats::lm` | `mtcars`, coefficients, standard errors, t tests, RSS, residual variance, log likelihood |
| Binomial GLM | `stats::glm` | `mtcars`, coefficients, standard errors, deviance, log likelihood, AIC |
| Poisson GLM | `stats::glm` | `warpbreaks`, coefficients, standard errors, deviance, log likelihood, AIC |
| Dense REML | `nlme::lme` | documented `ergoStool` random-intercept example, fixed effects/covariance and both variance components |
| Pedigree REML | `rrBLUP::mixed.solve` | additive relationship matrix with unphenotyped founders and repeated records; variances, BLUE, BLUPs, PEVs |
| MR | `MendelianRandomization` | shipped LDL-C/coronary-heart-disease example; fixed/random IVW, Q, MR-Egger, weighted-median point estimate |
| Meta-analysis | base R matrix algebra and `pchisq` | fixed inverse-variance pooling, Cochran Q, generalized DL random effects, and numeric meta-regression |

R and JLinAlg use different optimizers and termination rules. Closed-form and
direct linear-model quantities use tolerances near floating-point rounding.
IRLS standard errors use sub-micro tolerances. Variance-component and BLUP
comparisons allow a few `1e-5`; `rrBLUP` also adds `1e-6` to the diagonal of a
caller-supplied relationship matrix before its spectral REML optimization.
These tolerances are much smaller than scientifically reportable precision but
avoid treating optimizer-specific last digits as contractual.

The weighted-median point estimate is compared exactly to the R package's
deterministic estimator. Its bootstrap standard error is intentionally not
compared because R and Java use different random-number generators; each
implementation tests its own seeded reproducibility.

## Regeneration

Install the package versions above into an isolated R library and set
`JLINALG_R_REFERENCE_LIBRARY` if it is not at `.r-reference-lib` under the
project root. Then run:

```powershell
& 'C:\Program Files\R\R-4.6.1\bin\Rscript.exe' `
  'src\test\resources\r-reference\generate-reference.R'
```

Review package-version changes and numerical differences before updating Java
assertions. Generated output should never be accepted blindly: a material
difference may identify either an intentional estimator-contract difference or
a regression.

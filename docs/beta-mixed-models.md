# Sparse beta mixed models and pedigree effects

## Model and scope

`BetaMixedModel` fits proportions strictly inside `(0, 1)` with

```text
Y_i | b ~ Beta(mu_i phi, (1 - mu_i) phi)
logit(mu_i) = x_i' beta + z_i' b + offset_i
b_k ~ N(0, variance_k Q_k^-1).
```

It maximizes a first-order Laplace marginal likelihood. This is a likelihood
fit, not penalized quasi-likelihood (PQL). The sparse solver factors
`Z' W Z + blockdiag(Q_k / variance_k)` at conditional random-effect modes.
The marginal optimizer jointly refines fixed coefficients, log variances,
and log precision. The Laplace determinant uses the observed curvature,
including the noncanonical-link score term; Fisher weights are a working
iteration metric, not a substitute for the determinant's Hessian.
Symbolic sparse structure is prepared once per fit and reused by every
numeric factorization.

The initial API deliberately supports a logit mean link, random effects in the
mean predictor, and one constant beta precision. Fixed-only `BetaRegression`
continues to support all `betareg` mean/precision links and covariate-modeled
precision. Precision-side random effects, zero/one inflation, correlated
random intercept/slope blocks, AGQ, and profile-likelihood intervals are not
claimed here.

## Grouped and pedigree use

An ordinary random intercept uses the same sparse term API as other GLMMs:

```java
RandomEffectTerm site = RandomEffectTerm.randomIntercept("site", siteIds);
BetaMixedModelResult fit = BetaMixedModel.fit(
    proportion, meanDesign, List.of(site));
```

For an additive animal effect, `PedigreeRandomEffectTerm` supplies observation
incidence plus Henderson's sparse numerator-relationship precision `A^-1`:

```java
PedigreeRandomEffectTerm animal = PedigreeRandomEffectTerm.of(
    "animal", observationAnimalIds, pedigree);
BetaMixedModelResult fit = BetaMixedModel.fitPedigree(
    proportion, rowMajorMeanDesign, proportion.length, meanColumns,
    animal, null, null, BetaMixedModelOptions.defaults(),
    BackendPolicy.PREFERRED);
```

The fitted additive variance is `variance_a` in
`fit.varianceComponents()`. `fit.randomEffects("animal")` returns conditional
modes in pedigree order, including ancestors without phenotypes, while
`fit.componentPredictor("animal")` returns the observation-level genetic
contribution. Multiple grouped or arbitrary sparse-precision terms can be
combined with the general `fit` overload.

## Independent accuracy comparison

`BetaMixedModelRReferenceTest` uses a deterministic 600-row, 40-group data set
and compares the Java fit with `glmmTMB` 1.1.14 using
`beta_family(link = "logit")`. The fixture and full-precision reference are
regenerated by
`src/test/resources/r-reference/generate-beta-mixed-reference.R`.

| Quantity | `glmmTMB` | JLinAlg | Absolute difference |
| --- | ---: | ---: | ---: |
| Mean intercept | -0.3450862194 | -0.3450841607 | 0.00000206 |
| Mean slope | 0.8955822197 | 0.8955822672 | 0.00000005 |
| Beta precision | 17.18022176 | 17.18021128 | 0.00001048 |
| Random-intercept variance | 0.2626320509 | 0.2626327877 | 0.00000074 |
| Marginal log likelihood | 435.1762842886 | 435.1762842895 | 0.00000000094 |

The earlier Java value 435.2985387 (difference 0.1222544) was a defect, not an
acceptable difference between implementations of the same Laplace likelihood.
The corrected engine optimizes the marginal fixed effects and uses the
observed random-mode Hessian. The test also
proves that an unrelated-founder pedigree (`A = I`) is numerically identical
to the grouped random-intercept representation, and checks that unobserved
ancestors remain in the returned random-effect vector.

Run the accuracy gate with:

```powershell
.\gradlew.bat test --tests org.jlinalg.distributional.BetaMixedModelRReferenceTest
```

## Performance

The corrected-objective audit benchmark uses the same 600 observations,
40 groups and two fixed effects as the accuracy fixture. On the development
host (Windows, R 4.6.1, `glmmTMB` 1.1.14), five warm measured fits gave:

| Fit | Median time | Likelihood error against R |
| --- | ---: | ---: |
| JLinAlg grouped beta mixed model | 244.961 ms | 9.34e-10 |
| R `glmmTMB` grouped beta mixed model | 200 ms | baseline |

Java is about 1.22 times slower on this small workload. The old 30,000-row
11.20x grouped and 8.38x pedigree speed claims are withdrawn: they timed the
incorrect objective and do not certify the repaired solver. Corrected large
pedigree throughput has not yet been remeasured. Sparse incidence/precision
and symbolic reuse remain intact; no observation-by-observation covariance is
formed by this solver. Factor fill and the number of outer parameters still
govern scaling; sparse does not mean constant cost.

Reproduce both sides with:

```powershell
& 'C:\Program Files\R\R-4.6.1\bin\Rscript.exe' `
  src/benchmark/r/distributional_audit_benchmark.R
```

The matching Java entry point is `org.jlinalg.benchmark.DistributionalAuditBenchmark`.
See [distributional/GAM audit](distributional-gam-audit.md) for isolated
compilation commands, raw timings, checksums, and remaining limits. Every
timed fit must converge and meet the same-likelihood accuracy gate.

# TOPMed observed-variable SEM validation and performance

JLinAlg's SEM engine is a direct implementation of the observed-variable RAM
covariance relationship

`Sigma = (I - A)^-1 S (I - A)^-T`

with multivariate-normal covariance-structure maximum likelihood. It was not
ported from an R package. The independent R reference used here is `lavaan`
0.7-2.

## Model and data

The benchmark reads
`D:/Research/topmed/splicing-bmi/new/mastermat-batch1234-wcbc-ext.csv` and uses
4,680 complete observations on this 12-variable subset:

- `Sex`, `Age`, `BMI`, `Waist`;
- `Systolic_BP`, `Diastolic_BP`;
- `Glucose`, `HDL`, `LnTG`, `LogInsulin`;
- `CRP`, `eGFR`.

The full 57-column request has only five rows complete across every variable
(primarily because `AD` is missing in 4,886 of 5,029 rows), so complete-case
covariance ML on the full set is not estimable. The subset preserves most rows
while spanning several requested phenotype domains.

Columns are standardized over the common complete-case sample before timing.
The observed-variable path model is:

```text
BMI          ~ Age + Sex
Waist        ~ BMI + Sex
Systolic_BP  ~ Age + BMI
Diastolic_BP ~ Age + BMI
Glucose      ~ Age + BMI
HDL          ~ BMI + LnTG + Sex
LnTG         ~ BMI + Glucose + Sex
LogInsulin   ~ BMI + Glucose
CRP          ~ BMI + Sex
eGFR         ~ Age + Sex + BMI
Age ~~ Sex
```

All 12 variances are free. Other residual covariances are fixed to zero, giving
36 free parameters and 42 degrees of freedom. This is a numerical and
performance example, not a claim that the path directions are a
domain-validated causal model. Binary `Sex` is treated as Gaussian because the
current JLinAlg SEM scope is continuous observed-variable ML.

## Numerical agreement

Both engines use normal-theory ML, no mean structure, listwise-complete data,
random observed exogenous variables, expected-information standard errors, and
the same residual-covariance constraints. The fitted results agree as follows:

| Quantity | JLinAlg | lavaan 0.7-2 |
| --- | ---: | ---: |
| log likelihood | -70763.3172885 | -70763.3172885 |
| chi-square | 4497.68284338 | 4497.68284338 |
| df | 42 | 42 |
| CFI | 0.799908468824 | 0.799908468824 |
| TLI | 0.685570451009 | 0.685570451009 |
| RMSEA | 0.150559985169 | 0.150559985169 |
| SRMR | 0.0855176490074 | 0.0855176482142 |

Across all 36 parameters, the largest absolute estimate difference in this run
was below `1e-8`, and standard errors agreed below `5e-10`. A separate committed
lavaan fixture covers directed paths, free variances, an exogenous covariance,
a correlated residual, standard errors, likelihood, and fit indices. The
fixture is regenerated by
`src/test/resources/r-reference/generate-sem-reference.R`.

## Performance

On Windows 11 with an Intel Core i9-9900K, Java 21.0.4, R 4.6.1, and warmed
fits with input loading and standardization excluded, median wall times were:

| Runtime | Median seconds per fit |
| --- | ---: |
| JLinAlg CPU | 0.0081623 |
| lavaan 0.7-2 | 0.0700000 |

JLinAlg was 8.58 times faster in this run. The optimized engine uses an
analytic RAM likelihood gradient, BFGS updates, and analytic expected Fisher
information for standard errors. It converged in 22 likelihood evaluations;
the original implementation used derivative-free BOBYQA plus a finite-
difference Hessian and had no real-data SEM benchmark.

Reproduce both fits from the project root:

```powershell
.\gradlew.bat benchmarkTopmedSem
& 'C:\Program Files\R\R-4.6.1\bin\Rscript.exe' `
  src/benchmark/r/topmed_sem_benchmark.R `
  'D:/Research/topmed/splicing-bmi/new/mastermat-batch1234-wcbc-ext.csv' 11
```

Wall-time ratios are machine- and runtime-dependent. Repeat on an otherwise
idle host before using the ratio as a capacity-planning number.
